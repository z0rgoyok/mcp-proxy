# AGENTS

- Проект является автономным Kotlin JVM service (сервисом) для локального Generic MCP Proxy.
- Слои держать раздельно:
  - `domain` содержит доменные модели, value objects (объекты-значения), контракты и инварианты.
  - `application` содержит use cases (сценарии использования) и orchestration (оркестрацию).
  - `infrastructure` содержит Ktor, файловую систему, adb и внешние процессы.
  - `app` содержит launcher parsing (разбор режима запуска), wiring (сборку зависимостей) и output (вывод).
- `Main.kt` только собирает зависимости и запускает приложение.
- Runtime state (состояние запуска), journal bodies (тела журнала), CA keys (ключи сертификата) и временные данные хранить в `var/` и не коммитить.
- После изменений в коде обязательно запускать Qodana (кодана) по затронутому контуру или всему проекту.
- После Qodana обязательно запускать `./gradlew --no-daemon test`.
- Если менялся launcher (лаунчер), Dockerfile или Compose, обязательно запускать `./gradlew --no-daemon installDist` и проверять Docker/MCP запуск.
- Gradle-команды запускать последовательно.
